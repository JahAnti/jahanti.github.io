# JahAnti — seamless official logo update

This package removes the layered black decorative frame around the homepage logo. The original JahAnti artwork now fills the hero image area as one continuous image, preserving all artwork details.

## Publish
Upload the **contents** of this extracted directory to the root of the `JahAnti/jahanti.github.io` GitHub repository, including the `assets/` folder. Replace the existing `index.html` and `styles.css` and commit. No change to the existing website URL is required.

The logo image stays at `assets/jahanti-logo.png`; no transparency or editing of the original logo was necessary.
